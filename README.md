# є Світло

Каталог сонячного обладнання, оформлення замовлень і приватна адмінка: товари, акції, промокоди, склад, собівартість, замовлення, закупівлі, постачальники й архів.

## Локальний запуск

Потрібен Node.js 22 (щонайменше 22.12) або сумісна версія Node.js.

```sh
npm ci
npm run dev -- --port 5173
```

Магазин: http://localhost:5173/. Адмінка: http://localhost:5173/admin. Перші облікові дані встановлюються через локальну форму входу. Після чистого клонування каталог порожній: поточна база магазину зберігається окремо в локальній папці `data` і не завантажується до GitHub.

```sh
npm test
npm run build
```

GitHub Actions запускає тести й production-збірку. Автоматичні перевірки самі по собі ще не блокують публікацію на Vercel: захист основної гілки й порядок просування перевірених preview потрібно налаштувати під час підключення хостингу.

## Версії

Поточна версія — `1.0.0`, мітка Git — `v1.0.0`. Для наступних випусків використовуйте новий номер версії в `package.json`, відповідний lockfile, запис у `CHANGELOG.md`, коміт із номером версії та нову мітку. Старі мітки не переписуйте.

Історія Git зберігає код. Файли даних, облікові записи адміністратора, замовлення, оплати та залишки зберігаються окремо; перед операціями з даними робіть їхню резервну копію. Повернення коду не повинно стирати нові замовлення. Деталі відкату — у [плані Vercel](docs/VERCEL.md).

Інструкція адміністратора: [ADMIN.md](ADMIN.md). Поточні обмеження хостингу: [docs/VERCEL.md](docs/VERCEL.md). Збірка `dist` не містить локального API, тому повноцінний магазин ще потребує перенесення серверної частини та даних перед публікацією на Vercel.
